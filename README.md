## AI Photo Intelligence
AI Photo Intelligence is a privacy-focused desktop photo management application built with React, TypeScript, Tauri, Python, and FastAPI. It helps users import and organize local photo folders, search their library using natural language, classify images with local AI, detect duplicate and similar photos, manage favorites, create Smart Albums, and export custom albums as ZIP files.

The application processes photos locally using AI models, SQLite, and Qdrant, so the photo library and search data remain on the user’s device. The Tauri desktop layer provides native file access and packages the React interface together with the Python backend into an installable application.

The repository also includes a separate public website for presenting the product and distributing desktop installers for supported operating systems.
